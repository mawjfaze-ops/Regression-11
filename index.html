📖 About

A comprehensive Python package for regression analysis with built-in nonlinear-to-linear transformation capabilities. Perfect for students, researchers, and data scientists.

Key idea: Transform nonlinear equations into linear form, then solve using ordinary least squares — no complex optimization needed!

🚀 Features 8

📈

Linear Regression

Ordinary least squares with intercept. Includes matrix solution and step-by-step output.

y = w₀ + w₁x
🔢

Polynomial Regression

Fit polynomials of any degree. Linear in parameters — no nonlinear optimization.

y = Σ wᵢxⁱ
📉

Exponential Regression

y = a·e^(bx) linearized via natural log transform.

ln(y) = ln(a) + bx
⚡

Power Law Regression

y = a·x^b linearized via log-log transform.

ln(y) = ln(a) + b·ln(x)
🔄

Reciprocal Regression

Multiple forms: y = a + b/x, 1/y = a + bx, and more.

Y = A + B·X
🧩

Basis Functions

Custom φ(x) basis functions for flexible fitting.

y = Σ wᵢ·φᵢ(x)
🎯

MAP Estimation

Ridge regression with Gaussian prior. Tunable regularization.

w = (XᵀX + λI)⁻¹Xᵀy
📊

Model Quality Metrics

SSE, MSE, RMSE, R², and residual analysis.

R² = 1 − SSE/SST

💻 Quick Start

Run this example in your Python script:

import numpy as np from regression_solver import RegressionSolver # Create solver instance solver = RegressionSolver(verbose=True) # Your data x = np.array([1, 2, 3, 4, 5, 6, 7, 8]) y = np.array([2.1, 3.8, 5.2, 7.0, 9.1, 10.8, 12.5, 14.2]) # Run linear regression results = solver.linear_regression(x, y) # Check quality solver.model_quality(y, results['predictions']) # Make predictions new_x = np.array([9, 10]) pred = solver.predict(new_x, 'linear') print(f"Predictions: {pred}")

📄 Also try: python examples/example_runner.py for more examples
